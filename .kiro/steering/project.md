# Project Steering — Personal Dashboard

## Overview
This project is a personal dashboard web app built for the RevoU Coding Camp assignment.
It was developed using the Kiro IDE (AI-powered development environment).

## Tech Stack
- HTML for structure
- CSS for styling
- Vanilla JavaScript (no frameworks)
- Browser LocalStorage for data persistence

## Features
- Greeting with live time and date
- 25-minute Focus Timer (Start / Stop / Reset)
- To-Do List (Add / Edit / Mark Done / Delete) — saved in LocalStorage
- Quick Links (Add / Remove, opens in new tab) — saved in LocalStorage

## Folder Structure
```
index.html        ← main page
css/
  style.css       ← all styles (1 file only)
js/
  app.js          ← all logic (1 file only)
.kiro/
  steering/
    project.md    ← this file
```

## Constraints
- No backend server
- No frameworks (plain HTML/CSS/JS)
- Works as a standalone web app in modern browsers
